# Atlas Dev Days

Atlas Dev Days est le site web d’une conférence fictive destinée aux développeurs web. Il permet aux visiteurs de découvrir l’événement, son lieu et ses dates, de consulter le programme et les intervenants, puis de s’inscrire. Le site comprend quatre pages : Accueil, Programme, Intervenants et Inscription.

Il s’agit de mon premier projet réalisé à YouCode, dans le cadre du Brief 1 du Sprint 1. J’ai conçu la maquette des pages sur Figma avant de réaliser le site en HTML et CSS.

J’ai réalisé ce projet pour apprendre à passer d’une maquette à un site web, structurer plusieurs pages reliées par un menu et créer une interface lisible sur ordinateur comme sur mobile. Il m’a permis de pratiquer les bases du HTML et du CSS et de découvrir les différentes étapes d’un projet web.
